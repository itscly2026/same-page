# Retain personal layers temporarily after membership removal

Removing or leaving a choir immediately revokes cloud access and synchronization, but the former member's server-side personal layers remain recoverable for thirty days before deletion. Reinstating the same membership during that window restores them; already downloaded content cannot be remotely recalled, and unsynchronized local personal drafts are not silently deleted. This balances prompt authorization revocation with recovery from accidental removal without granting choir administrators access to private annotations.

Public preview is an explicit exception: authenticated preview access and ownership of personal layers do not depend on membership. Removing a preview membership immediately revokes its shared-layer grants and administrative permissions, but does not revoke the user’s preview access or start a thirty-day deletion period for their personal layers; this preserves the promise that any signed-in user can keep using private annotations in the public experience.

Only a current drive administrator may reinstate a removed membership within the recovery window. Restoration retains the same membership identity but returns it as an ordinary member without old shared-layer grants. At expiry, ordinary-drive personal layers, user preferences and the removed membership are purged; a later join is a new membership. A pending user deletion holds identity and personal data until its own recovery deadline. The last active administrator cannot leave, be removed or be demoted until another active administrator exists; this invariant is checked atomically.
