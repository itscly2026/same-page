# Isolate product authentication from Webmail

Same Page will self-host Better Auth password authentication on its Worker and D1, and send registration-verification and password-reset OTP messages directly through Resend from `login@samepage.clyapps.com`, using the dedicated `samepage.clyapps.com` sending domain and a separate domain-restricted Sending-only key. Every accepted OTP request shares a server-enforced mailbox cooldown plus mailbox and client windows; the stored limit identities are HMAC-protected, and the same limits are consumed for deliverable and non-deliverable addresses so the response does not disclose whether a user exists. Daily sign-in uses the user's email and password rather than an OTP. Same Page reuses the existing `clyapps.com` mail-provider foundation but does not call the fixed-user Webmail API, share its secret, change root-domain MX, or write authentication messages into its Sent mailbox; this preserves the Webmail and sender-reputation boundaries while keeping low-volume authentication within the free service tiers.
