# Use a content-first single-page reader shell

Same Page will use an iPad-first reader in which the score is the sole primary content: a score first opens in 翻页模式 fitted to one whole page in every orientation, while 连续滚动模式 remains an optional per-score preference, and all reader chrome stays hidden until a central tap after a one-time first-use hint. In 阅读模式, edge taps or horizontal swipes turn pages, pinch and drag zoom or pan, a page turn restores whole-page fit, the last page and layout are restored on the same device only, and thumbnails, layers, layout, offline, and synchronization controls appear in overlay panels; only a new PDF version, a local conflict, or local-data risk may interrupt the score. 编辑模式 focuses and locks the current page—even when entered from 连续滚动模式—and keeps the revealed top controls in place with only the edit control shown as selected; toggling that control off restores the previous reading layout and position. Always-visible reading chrome, reflowing sidebars, two-page spreads, cross-device reading-position sync, and editing across pages are deliberately excluded because they dilute score focus or add complexity to the first version.

Entering or leaving editing preserves the current page's scale and viewport position. In continuous reading, editing hides and disables neighbouring pages while retaining the existing page geometry and scroll container; rebuilding a fitted single-page layout would lose the user's place. Finishing reveals the same reading layout without a scale conversion or scroll restoration.

A user-triggered system-fullscreen control is available in the reading options, with unsupported/rejected requests handled without interrupting reading. The background fills the viewport but the score fitting area and controls respect all four device safe areas. Browser and installed-app policies retain authority over system status bars; fullscreen support is not an installation or reading requirement.
