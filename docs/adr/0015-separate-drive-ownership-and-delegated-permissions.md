# 云盘拥有权与可委托操作权限分离

云盘始终归属于一个有效成员；拥有权独立于操作授权，只有拥有者可转让拥有权、任命或调整受托权限管理者。独立的操作权限和授权管理范围取代 admin/member，避免上传文件的人自动获得删除文件、移除成员等无关能力；受托人只能在其范围内调整普通成员，不能自提权或继续转委托，其离任不级联撤销此前发出的授权。

共享层编辑按稳定槽位授权，或明确授予全部共享层（包括未来新增层）；配置层不授予内容编辑权。个人层始终只允许本人编辑，拥有权、操作授权和受托范围均不覆盖个人层隐私。授权在写入事务中重新验证，离线失权草稿保留并按层暂停，不能承诺即时撤回断网设备已有内容。

拥有权转让只改变归属，原拥有者保留显式授权；成员关系终止清除所有显式权限和管理范围，恢复不复活旧特权。既有云盘只有一位有效管理员时可确定其拥有者；其他情况必须由部署操作明确提供有效成员映射，缺失或无效时迁移失败。公开体验和访客准入仍由部署配置决定，不属于可授权操作。
