# 云盘配置共享层，个人层按谱向成员分享

共享层身份由云盘定义，E/S/A/T/B 只作为新云盘初始配置，具备共享层配置权限的成员可新增、改名、排序、停用与重新启用，以适应不同排练分工。保留稳定槽位、已有批注和云盘级授权/偏好，停用不删除内容。

个人层默认私有，作者按谱向云盘成员分享，成员可只读订阅作者持续更新的笔记。采用逐谱开启而非云盘级自动公开，避免顺手记下的私人内容在其他谱上被意外分享；取消分享或作者离开云盘后撤销访问与订阅，离线副本联网同步后清理。此决定取代 ADR-0012 的固定五层和个人层始终私有约束，其订阅与编辑权限分离、编辑模式只显示当前层的原则继续适用。

共享层删除采用独立于停用的三十天回收期，作用于云盘全部乐谱的同一稳定槽位。回收期间保留启用标志、批注对象、授权、排序及偏好，恢复不重建槽位，也不恢复已终止成员关系。期限在恢复写入时检查，后台尚未物理清理不能延长恢复期。定期清理以带到期条件的槽位删除及原子关联清理完成，与恢复竞争时只允许一方生效。

删除和恢复使用层修订号检测过时操作；管理更新递增修订号，已删除层拒绝设置、排序、授权和偏好更新。批注写入在 D1 事务中重新校验层状态与有效成员权限。响应丢失时重新查询当前/已删除列表确认状态，不按名称推断结果。

断网设备无法即时撤回内容。所有 outbox 上传路径先刷新层能力，仅发送当前有编辑权的层；已删除或停用层的本机草稿及冲突保留，原层恢复且权限允许后按既有对象冲突规则继续。同名新建层获得新槽位，永不接收旧草稿。收到不可用状态后更新当前 owner 的云盘离线快照，保持谱面文件和其他层；正在输入的内容可完成为原层本机草稿，再停止新的编辑。

云盘另有单调共享层状态修订号，在槽位新增、更新和永久清理时推进。阅读器层列表与该修订号在同一 D1 快照中读取；管理页收到删除确认或查询结果后，以同一 owner/session 校验更新本机缓存。Dexie 在同一事务内记录最新云盘修订并移除不可用槽位，拒绝较旧的跨乐谱、跨标签页响应，避免断网后旧快照使已删除层重新显示。

ADR-0015 将层配置与内容编辑、授权管理分开；配置能力不隐含内容编辑或授权管理。成员权限通过统一成员页面调整，拥有者始终可编辑共享层，受托范围按稳定槽位或明确的全部共享层授权。
