# Retain shared attribution after account deletion

Deleting an account immediately disables access and starts a thirty-day recovery period for identity data and personal layers, after which they are deleted. Shared annotations remain choir content and retain the author's final choir-specific display name rather than becoming anonymous; this retained attribution is disclosed during account deletion and contains neither the login email nor a global profile name. The user must first arrange another administrator for any choir where they are the only administrator.
