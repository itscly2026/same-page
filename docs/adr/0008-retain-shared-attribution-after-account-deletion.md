# Retain shared attribution after account deletion

Deleting an account immediately disables access and starts a thirty-day recovery period for identity data and personal layers, after which they are deleted. Shared annotations remain choir content and retain the author's final choir-specific display name rather than becoming anonymous; this retained attribution is disclosed during account deletion and contains neither the login email nor a global profile name. The user must first transfer every drive they own to another active member.

Deletion requires a new verification using an already associated authentication method after the deletion flow starts, followed by explicit confirmation within ten minutes. A deleted identity may authenticate only to confirm recovery within thirty days, using the method used for deletion; it has no product access until restoration. Recovery preserves the user identity and memberships terminated by that deletion, as ordinary members without old edit grants; earlier removals remain removed. Final display-name changes participate in the synchronization feed, and shared operation history survives identity deletion with nullable actor references. Local drafts remain associated with the original user rather than being silently erased or transferred.
