# Merge annotation objects instead of page snapshots

Shared layers allow multiple editors, so synchronization will treat strokes and text as stable annotation objects rather than replacing an entire page-layer snapshot. Changes to different objects merge automatically; when the same object has changed, the server keeps only its already accepted canonical version and rejects the later operation instead of storing a cloud conflict or silently overwriting either editor. The rejected variant remains a local conflict only on the submitting device until that editor reapplies it, keeps both versions as separate objects, or discards it. Editing is continuously persisted as a local draft, while the user's completion action publishes a batch: online responses distinguish synced, partially merged, and locally conflicting results, and offline completion remains visibly pending until synchronization.
