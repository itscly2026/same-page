# 多个个人层与逐对象工具色

依据 #209，个人层的身份改为稳定层 ID；移除一人一谱唯一约束，保留开箱可用的“我的笔记”，每层独立命名、显示、分享、回收及恢复。此决定取代 ADR-0012/0014 的单个人层假设，分享仍严格限定于本谱本层的云盘成员只读权限；删除保留三十天恢复期并停止分享，恢复不重新分享，本机未同步内容不随服务器层删除销毁。

文字、画笔、荧光笔及形状颜色属于对象内容，进入已有对象编辑时保留其颜色；撤销、同步、离线快照和 PDF 导出使用同一对象数据。文字、画笔、形状和荧光笔分别在本机按用户记忆工具颜色，不为个人层增加颜色覆盖或跨设备偏好系统。共享层显示色则属于读者偏好，依次取本谱、云盘用户、云盘配置和产品默认红色；既有显式配置不重写。

层元数据修改使用修订号，避免旧名称、分享或删除请求覆盖新意图。删除在服务端立即阻止后续对象写入并撤销订阅；本机保留失去编辑能力的草稿和冲突，恢复原层后仍按对象 OCC 处理。个人层新增使用客户端生成的层 ID，使响应丢失后的重试不会创建第二个层。
