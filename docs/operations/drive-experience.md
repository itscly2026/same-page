# 云盘启动、离线与名称管理

默认启动恢复当前用户最后进入的成员云盘，不展示继续阅读卡片。无历史时单云盘直接进入，多云盘显示选择；历史云盘不在最新成员列表时先提示再让用户选择。邀请和深链接优先，乐谱进度仍在主动打开时恢复。

本机目录与在线目录使用同一云盘页面。目录记录的成员身份和管理员角色只用于恢复导航和显示禁用入口，不能授权云端请求；公开体验目录不进入成员云盘切换或启动候选。尚无成员导航记录的旧副本仍可从原乐谱/云盘链接恢复，不由副本推断成员关系。

离线可搜索与排序本机目录；完整校验通过的副本可打开，只有目录的文件显示需联网下载。连接恢复后原地更新。管理员离线仍能看到管理入口，但不能提交管理操作。服务端失权与网络故障分别处理，遵守 ADR-0004。

用户菜单提供“我在此云盘的显示名”；管理员从云盘菜单修改“云盘名称”，或进入“成员与管理员”交接。名称提交使用修订号，冲突时保留输入、展示当前值，须再次保存才覆盖。成员显示名只改当前 Membership，不重写历史批注署名或归属。管理员交接沿用先授予新管理员再降级或退出的流程；数据库保护最后一名管理员。

## 发布与验收

部署前应用 `0018_drive_name_revision.sql`。API 的权限与并发测试、页面回归，以及 Chromium 的实际离线重启 / WebKit 的新页 API 故障测试分别提供证据。Playwright WebKit 测试不等同于 iOS 安装 PWA 的离线进程重启。

iOS / Android 安装 PWA 仍须实机验证：从图标启动到最后云盘、断网刷新、切换云盘、恢复联网保持浏览位置，以及管理员交接后的权限变化。PR / CI 通过不代表生产部署或真机验收完成。
