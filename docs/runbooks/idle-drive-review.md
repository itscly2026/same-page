# 免费体验云盘闲置检查

当前只提供产品告知，未实现自动活跃追踪、通知邮件或闲置清理任务。维护者后续人工检查时：

1. 先确认拥有者的可投递邮箱，以及能可靠证明任一成员最近联网访问该云盘的记录。记录不足时，不将云盘判为闲置；离线打开已有副本不可作为服务端已知访问。
2. 连续超过 30 天无成员联网访问的云盘可以进入人工通知流程，超过门槛不等于立即删除。
3. 向拥有者发送邮件，明确云盘、拟清理日期（至少在发信 14 天后）、影响及保留方法：通知期内任一成员重新联网访问该云盘，即取消本次清理。不要把邀请码或成员邮箱清单写进公开日志。
4. 完整通知期结束后复查。发现成员重新联网访问就取消；通知失败或无法核实访问时不执行清理。
5. 实际清理属于后续独立运营操作，本功能改动不授权立即清理任何云盘。按既有产品删除边界处理，不承诺清理后恢复。

该运营规则不改变回收站、历史 PDF 或已删除用户现有的保留与清理机制。
