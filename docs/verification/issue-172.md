# #172 本地验收记录

本轮在 `codex/issue-172` 独立 worktree 验证，已 rebase 到 `main` 的 `0015b15`，保留 #176 的共享层删除与恢复行为。以下均为本地证据，不代表生产发布或真实移动设备验收。

## 实现边界

- 公共退出协调器统一处理 React Router 历史、界面返回、内部链接和 React Aria 弹层：先关闭最上层，再持久化编辑，最后退出页面；显式目标在安全退出后继续。深链接首次出现可退出层时建立临时同文档历史点，无退出层时越过重复入口，允许返回站外。
- 文字输入提交到当前页后再完成编辑；连续滚动的相邻页不会覆盖当前输入的提交入口。本机保存失败保留输入并可重试。图层动作与重复退出共享持久化任务。
- 云盘头像直接登出，复用待同步确认、服务端注销及本机隐私清理；持久化 logout fence 阻止旧会话和跨标签身份恢复。服务端失败与本机清理失败分别提示。
- 本机存储只清理当前可管理的 PDF 文件，保留目录、草稿、outbox、冲突和登录状态。分级持久化 fence 与离线激活处于同一事务边界，阻止删除前启动的下载回写；持有的文档继续阅读，新打开可重新下载。
- 内容优先加载、侧栏/头像入口、首页页尾、次级操作及默认英文声部名称同步收敛；自定义名称不改写。

## PR #178 CI 修复

首次 CI 的 `integration` 在性能脚本查找“返回云盘”链接时超时，`verify` 因该失败正确拒绝放行。返回控件已经统一为按钮，两个测量脚本遗漏了角色迁移。使用 `node scripts/measure-loading-performance.mjs` 本地复现相同超时后，将受控与生产测量脚本同步改为查找按钮。

原性能门槛保持不变。修复后受控 WebKit 测量通过：缓存返回 67 ms（门槛 200 ms），首次开谱 538 ms，再次开谱 31 ms。生产测量脚本仅完成 lint/语法校验，未进行生产测量。
