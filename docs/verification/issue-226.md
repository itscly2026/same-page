# #226 云盘导航与设置 UI 验收

本改动在 #225 的读取资源、阅读偏好持久化和修改/刷新结果区分机制上完成 UI 集成。外层个人菜单继续管理账户、帮助、关于和退出登录；云盘内入口只处理云盘显示名、阅读偏好、本机存储和成员身份退出。

## 行为覆盖

- 云盘抽屉保留返回云盘列表及管理入口；Esc、浏览器返回、可见关闭按钮与焦点恢复均沿用导航机制。
- 本机存储显示总大小、乐谱数量、逐文件校验状态与清理操作。完整校验复用 `useOfflineScore`，存在 Blob 不代表可离线；批量清理部分失败时只重试失败乐谱，保留云端内容及本机草稿、待同步操作、冲突。
- 成员列表移除重复角色，保留“我”和已移除状态；拥有者信息在详情内，具体操作权限和授权范围仍可查。
- 成员与共享层视图使用同一 React Aria 分段选择，选中、禁用、焦点和处理中语义分别表达，支持方向键。
- 个人层日常行包含显示勾选和“公开”switch，说明云盘成员可见或仅自己可见。标题菜单承担单层快捷管理、多层明确目标的管理和恢复；删除前保留未同步内容保护。
- 公开等修改须服务端确认。修改成功但刷新失败时只重试刷新；即使删除后目标行消失，仍保留其名称、反馈与重试入口。
- 手机首页主入口独占首行；示例、安装入口在次行，任一或同时隐藏均自然排布。
