# 云盘变更影响（#285）

`navigation-events` 集中请求分类和变更影响；`ReadResource`、`DriveLibrary` 与目录缓存只执行自己的失效生命周期。读取身份显式区分 owner、driveId、kind、variant，内存 key 的编码由读取注册表拥有，消费方不再解析冒号片段。

新增操作时在 `observeNavigationResponse` 确定是否属于导航变更，再在同 module 指定读取依赖、目录影响及是否撤下确认能力。新增读取种类必须明确 `DriveReadKind` 及依赖；共享层详情和列表变体仍分别缓存。没有新增持久化格式或服务端协议。

`drive-library.test.ts` 从请求观察入口同时验证设置读取、活动目录、目录缓存与返回标记：显示名、云盘名称、文件恢复、共享层、成员关系、拥有权、彻底删除、401/403、其它失败、GET/HEAD，以及谱内修改的排除规则。另验证目录在途旧响应不会重新填回缓存。

`read-resource.test.ts` 验证资源复用、身份与种类字段碰撞隔离、按云盘撤销、设置在途旧响应隔离和会话替换。既有 60 秒新鲜期、服务端授权与离线副本语义保持。
