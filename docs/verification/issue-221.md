# #221 离线故障隔离与阅读器呈现验证

## 证据边界

- 原实现上正式故障注入测试失败：同 owner/云盘另一谱子的文件重写抛出 `NotFoundError`，当前谱子清理后、outbox 为 0，重新准备返回 failed。快照独立存储后该场景通过。
- 独立阅读器测试在原实现失败：文档 ready 但没有首屏呈现回调，超过 45 秒仍保持 ready。现在进入可重试错误；已确认呈现的对照组不会误超时。现有取消、源切换、PDF 故障分类和回退测试保留。
- 以上均为合成故障边界，不能证明真实 iPad 的底层 Blob 异常原因，也不能声称完整复现设备报告。

## 存储恢复

版本 11 升级逐条提取快照，不重写旧 Blob。拒绝 Blob 重写的升级测试仍须通过，并验证文件字节、草稿、outbox、conflict 保留。旧文件物理记录可能带有不再使用的旧快照字段；运行时只读取独立快照表，没有旧字段回退。后续文件替换自然写入不含旧字段的新记录。

无法读取的单条旧文件保留原记录，升级继续处理健康文件；缺少或结构损坏的快照不能证明可离线，且不参与其他谱子的权限事务。正常快照仍按当前修订撤回共享层和取消分享内容。目标谱子缺失快照时可重新准备，不会因 active-copy 比较卡死。

## 真实设备待验

未部署，未取得真实 iPad PWA 验收。发布后先核对 buildId，再验证打开、下载、清理后重试、断网重开及联网同步。不要用清空网站数据或重装代替升级验收。
