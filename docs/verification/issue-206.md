# #206 设置、准入、找谱和批注职责整理

基线：已合并 #205 的 `2b2af8a`。独立 worktree：`same-page-issue-206`；分支：`codex/issue-206`。

## 实现

- `/user` 为不依赖生命周期请求的个人设置页；`/user/lifecycle` 承载删除与恢复，`/choirs/:choirId/me` 独立承载退出。头像菜单仅保留身份、个人设置与退出登录。原身份验证、拥有权交接、三十天恢复期和原归属草稿规则保持不变。
- 设置写入以服务端成功响应为确认点，区分保存失败、结果未确认、已保存但后续读取失败及身份/权限失效。成员版本冲突提供重新读取入口，表单修改跨刷新保留；日志读取失败与无记录分开。页面生命周期隔离迟到结果。
- DriveLibrary 在连接失败时保留最近目录与列表视图。明确失权立即撤销云端操作，沿用同一搜索、排序及打开界面显示经过现有离线校验的本机副本；损坏或清理后更新列表。归属隔离的失权记录保留至成功的云端目录确认，认证缺失不创建失权记录。
- 首页邀请码、登录后续接及开放准入共用准入/成员检查、加入与凭证清理规则。公开体验不创建成员关系；移除的成员不会被引导到开放加入。取消等待在途会话操作结束后清理凭证，并隔离迟到跳转。
- 阅读器通过批注意图接口执行可靠入队、重试同步、丢弃/重应用/保留双方冲突。继续使用现有 sync/outbox 调度及对象级冲突实现，不将同步放入 ReaderSession。
